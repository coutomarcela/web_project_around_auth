# Around

## Descrição

Around é uma aplicação web de compartilhamento de fotos, desenvolvida com React. A plataforma permite que usuários criem uma conta, façam login e acessem funcionalidades de interação com fotos e perfis.

Entre as funcionalidades disponíveis estão:

- Cadastro e autenticação de usuários.
- Login e logout.
- Proteção de rotas para usuários autenticados.
- Exibição de fotos em cartões.
- Adição e remoção de fotos.
- Curtir e descurtir fotos.
- Edição das informações do perfil.
- Atualização da foto de perfil.
- Exibição de mensagens de sucesso e erro por meio de popups.

## Tecnologias e técnicas utilizadas

- **JavaScript (ES6+):** desenvolvimento da lógica e manipulação de dados.
- **React:** construção da interface por meio de componentes reutilizáveis.
- **React Router:** gerenciamento de rotas e navegação entre páginas.
- **Context API:** compartilhamento de informações do usuário e estado de autenticação entre componentes.
- **HTML5 e CSS3:** estruturação e estilização da interface.
- **Vite:** configuração do ambiente de desenvolvimento e execução da aplicação.
- **API REST:** comunicação entre o frontend e o backend para autenticação e gerenciamento de dados.

### Técnicas e conceitos aplicados

- Componentização e reutilização de elementos.
- Gerenciamento de estado com React Hooks (`useState` e `useEffect`).
- Renderização condicional.
- Consumo de APIs e tratamento de respostas assíncronas.
- Autenticação com token JWT e armazenamento no `localStorage`.
- Implementação de rotas protegidas.
- Organização de estilos CSS por componentes.
